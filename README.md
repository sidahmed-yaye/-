# موعدي — منصة SaaS لحجز مواعيد العيادات

نظام حجز مواعيد متكامل للعيادات الصغيرة والمتوسطة في موريتانيا، مع تذكيرات واتساب تلقائية،
لوحة إدارة مركزية، نظام اشتراك وفوترة، دليل عام للمرضى، وملفات مرضى دائمة عبر الشبكة.

## البنية

```
clinic-booking/
├── backend/
│   ├── server.js          نقطة الدخول
│   ├── db.js               طبقة قاعدة البيانات (SQLite المدمجة في Node — بدون تبعيات خارجية)
│   ├── utils.js             أدوات مشتركة (الوقت، التحقق من الهاتف)
│   ├── middleware/auth.js   مصادقة العيادات + مصادقة الأدمن
│   ├── routes/
│   │   ├── auth.js          تسجيل/دخول العيادات
│   │   ├── clinic.js        إعدادات العيادة، الفوترة، الإحصائيات، سجل المريض
│   │   ├── appointments.js  إدارة المواعيد من لوحة العيادة
│   │   ├── public.js        الحجز العام + الدليل + الدفع المسبق
│   │   └── admin.js         لوحة الإدارة المركزية
│   ├── services/
│   │   ├── whatsapp.js       إرسال الرسائل (وضع تجريبي بدون بيانات اعتماد حقيقية)
│   │   └── scheduler.js      مُجدوِل تذكيرات الـ24 ساعة (كل 15 دقيقة)
│   ├── data/
│   │   ├── clinic.db          قاعدة البيانات (تُنشأ تلقائياً)
│   │   └── uploads/            صور إثبات الدفع المرفوعة
│   └── public/                 كل الواجهة الأمامية
│       ├── index.html          تسجيل دخول/حساب العيادة + اللوحة الكاملة
│       ├── book.html            صفحة الحجز العامة (رابط: /book.html?clinic=SLUG)

└── README.md
```

## التشغيل محلياً

```bash
cd backend
npm install
cp .env.example .env     # عدّل JWT_SECRET و ADMIN_USERNAME/ADMIN_PASSWORD
npm start
```

- لوحة العيادات: `http://localhost:3000`
- دليل البحث العام: `http://localhost:3000/directory.html`
- لوحة الإدارة: `http://localhost:3000/admin.html`

## المراحل المُنجزة

1. **الأساس**: قاعدة بيانات SQLite حقيقية (لا تبعيات native)، حالات حجز كاملة (Pending/Confirmed/Rejected)، قفل الوقت مضمون على مستوى القاعدة نفسها (يمنع الحجز المزدوج حتى في حالات التزامن الحقيقي)
2. **لوحة الإدارة** (`/admin.html`): تعطيل/تفعيل أي عيادة فوراً، متابعة كل العيادات، التحكم بالمستحقات وتصفيرها
3. **الاشتراك والفوترة**: 14 يوماً مجانية تلقائياً لكل عيادة جديدة، ثم 10 أوقية لكل حجز مؤكد، سجل مدفوعات كامل
4. **الإحصائيات والتقارير**: ملخصات يومية/أسبوعية/شهرية لكل عيادة + رسم بياني لاتجاه الحجوزات
5. **الدليل العام** (`/directory.html`): بحث وتصفية حسب الاسم/التخصص/المدينة، حجز مباشر بنفس آلية الرابط الخاص
6. **ملف المريض الدائم**: هوية مريض موحدة عبر كل العيادات (بالهاتف)، مشاركة اختيارية للملاحظات بين العيادات (معطّلة افتراضياً، تتحكم بها العيادة صاحبة الزيارة لكل زيارة على حدة)
7. **الدفع قبل التأكيد**: كل عيادة يمكنها تفعيل طلب إثبات دفع إلزامي قبل الحجز (رفع صورة)، مع عرض معلومات الدفع (اسم الخدمة، الرقم، تعليمات) للمريض تلقائياً

## ⚠️ نقطة حرجة: التخزين الدائم على Railway

قاعدة البيانات (`data/clinic.db`) وصور إثبات الدفع (`data/uploads/`) تُخزَّن كملفات على القرص.
**على استضافة مثل Railway، هذا التخزين مؤقت افتراضياً** ويُمسح عند كل إعادة نشر (Redeploy) ما لم تُضِف **Volume دائم** مرتبط بمجلد `backend/data`.

**يجب إضافة هذا قبل استخدام حقيقي مع عيادات وعملاء فعليين.**

## تفعيل واتساب الحقيقي

بدون إعداد، الرسائل تُسجَّل في `backend/data/whatsapp-dev-log.txt` بدل الإرسال الفعلي. للتفعيل الحقيقي:
1. أنشئ حساباً على [Meta for Developers](https://developers.facebook.com)
2. فعّل WhatsApp Business Platform (Cloud API)
3. ضع `WHATSAPP_TOKEN` و `WHATSAPP_PHONE_ID` في `.env`
