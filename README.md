# موعدي — نظام حجز وتذكير للعيادات الصغيرة (MVP)

نظام SaaS بسيط: كل عيادة تنشئ حساباً، تحصل على رابط حجز خاص بها تشاركه مع مرضاها،
والنظام يرسل تذكيراً تلقائياً عبر واتساب قبل كل موعد بـ24 ساعة لتقليل نسبة الغياب.

## البنية

```
clinic-booking/
├── backend/          خادم Express + قاعدة بيانات ملف JSON (بدون تبعيات native)
│   ├── server.js
│   ├── db.js         طبقة البيانات
│   ├── routes/        auth.js (تسجيل/دخول) · appointments.js (لوحة العيادة) · public.js (صفحة الحجز العامة)
│   ├── services/      whatsapp.js (إرسال) · scheduler.js (مُجدوِل التذكيرات كل 15 دقيقة)
│   └── data/db.json   قاعدة البيانات (تُنشأ تلقائياً)
└── frontend/
    ├── index.html      تسجيل الدخول ولوحة تحكم العيادة
    ├── book.html        صفحة الحجز العامة للمرضى (رابط: /book.html?clinic=SLUG)
    └── css/js
```

## التشغيل محلياً

```bash
cd backend
npm install
cp .env.example .env     # عدّل JWT_SECRET
npm start
```

افتح `http://localhost:3000` → أنشئ حساب عيادة → ستحصل على رابط حجز تشاركه مع مرضاك.

## تفعيل إرسال واتساب الحقيقي (بدل الوضع التجريبي)

بدون إعداد، النظام يعمل في **وضع تجريبي**: الرسائل تُسجَّل في `backend/data/whatsapp-dev-log.txt` بدل إرسالها فعلياً — مفيد للتجربة والعرض التوضيحي على العملاء المحتملين.

للإرسال الحقيقي عبر واتساب:
1. أنشئ حساب على [Meta for Developers](https://developers.facebook.com)
2. فعّل **WhatsApp Business Platform (Cloud API)** على تطبيقك
3. احصل على `Access Token` و `Phone Number ID`
4. ضعهما في ملف `.env`:
   ```
   WHATSAPP_TOKEN=...
   WHATSAPP_PHONE_ID=...
   ```
5. أعد تشغيل الخادم

ملاحظة: في البداية يعطيك Meta رقم اختبار مجاني (25 رسالة/يوم لأرقام محددة مسبقاً) — كافٍ لعرض المشروع على أول عملاء. للانتقال للاستخدام الفعلي غير المحدود تحتاج توثيق حساب العمل (Business Verification)، وهي خطوة إدارية تستغرق أياماً قليلة.

## التحديثات الأخيرة (بعد أول اختبار حقيقي على Railway)

- ✅ **إعدادات العيادة قابلة للتعديل**: قسم جديد "إعدادات العيادة" في لوحة التحكم لتغيير أوقات الدوام، مدة الموعد، الاسم، الهاتف — في أي وقت بعد التسجيل
- ✅ **إشعارات واتساب فورية**: رسالة تأكيد استلام فور حجز المريض، ورسالة عند تأكيد/إلغاء/تعديل الموعد من العيادة (بالإضافة لتذكير الـ24 ساعة الموجود مسبقاً)
- ✅ **لغة فرنسية اختيارية**: زر تبديل "Français / العربية" في أعلى لوحة التحكم وصفحة الحجز — العربية هي الافتراضية دائماً. رسائل واتساب تبقى بالعربية دوماً بغض النظر عن اختيار لغة الواجهة.
- ✅ **إصلاح جذري لمشكلة "إضافة موعد يدوي لا يعمل"**: كانت المواعيد تُحوَّل عبر `Date.toISOString()` والتي تعتمد على المنطقة الزمنية للمتصفح، فيحدث انزياح ليوم كامل أحياناً بين متصفح العميل وخادم Railway. الآن يُخزَّن الوقت كنص محلي خام دون أي تحويل، ويُفترض دائماً توقيت موريتانيا (UTC+0 بلا توقيت صيفي) عند حساب مواعيد التذكير فقط.
- ✅ **التحقق من صيغة الهاتف الموريتاني**: أي رقم هاتف (عيادة أو مريض) يُرفض تلقائياً إن لم يكن 8 أرقام تبدأ بـ 2 أو 3 أو 4

## الخطوات التالية المقترحة (بعد MVP)

- **نشر على استضافة حقيقية**: Railway أو Render (مجاني للبداية) بدل التشغيل المحلي
- **الانتقال من JSON إلى قاعدة بيانات حقيقية** (PostgreSQL) عند تجاوز عدد قليل من العيادات المتزامنة
- **صفحة تسعير + دفع Bankily/Masrivi** لتفعيل النموذج التجاري
- **تسجيل دخول متعدد المستخدمين لكل عيادة** (سكرتيرة + طبيب بصلاحيات مختلفة)
- **تذكير ثانٍ** صباح يوم الموعد بالإضافة لتذكير الـ24 ساعة
